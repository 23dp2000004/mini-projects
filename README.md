### notes folders:

These are versions of a notes app.
Each version is implemented stand alone and then combined into one that has all the features.

- notes-combined : has all the features.
- notes-v1 : can add and view notes (base code).
- notes-v2 : can edit notes.
- notes-v3 : can delete notes.
- notes-v3.5 : can see character count while typing note, can favorite/unfavorite notes, biggger text box.
- notes-v4 : can mark notes as pending/done.
